# Changesets

Pending release notes, one Markdown file per change. Add one with `pnpm changeset` whenever a change should reach a release.

The Hub (`apps/server`, `apps/worker`), the Dashboard image and the CLI share one app version (the `fixed` group in `config.json`); `@mitcsutt/embertrail-client` versions on its own. See [Changesets](https://github.com/changesets/changesets) for the file format.
