# Embertrail

Self-hostable telemetry hub for AI coding agents. Claude Code sends OpenTelemetry straight to it; a Kiln-based dashboard reads it back. Modular, multi-user, and each part runs on its own.

**Status: design phase.** No code yet. The design lives in this repo's issues, labelled `design`, `adr` and `spec`.
