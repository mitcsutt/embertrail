# Embertrail

Self-hostable telemetry hub for AI coding agents. Claude Code sends OpenTelemetry straight to it; a Kiln-based dashboard reads it back. Modular, multi-user, and each part runs on its own.

**Status: building.** The design is locked and lives in this repo's issues, labelled `design`, `adr` and `spec`; build work is tracked in the `epic` issues, starting with Core (#49). The workspace, CI and tooling are in place; the Hub itself isn't usable yet.

To work on it, see [`CONTRIBUTING.md`](CONTRIBUTING.md) and [`docs/development.md`](docs/development.md). To report a security problem, see [`SECURITY.md`](SECURITY.md).
